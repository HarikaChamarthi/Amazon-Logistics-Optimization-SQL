# Amazon Logistics Optimization Using SQL

## Project Overview

This project focuses on analyzing Amazon's logistics operations using SQL to identify delivery delays, optimize delivery routes, evaluate warehouse performance, and improve shipment efficiency.

The project demonstrates practical SQL skills by solving real-world logistics problems through data cleaning, querying, aggregations, window functions, common table expressions (CTEs), joins, subqueries, and KPI reporting.

---

## Business Problem

Amazon handles millions of deliveries every day. Delays in delivery routes, warehouse processing, and shipment tracking can increase operational costs and reduce customer satisfaction.

This project analyzes logistics data to identify bottlenecks, optimize routes, and generate business insights for improving operational efficiency.

---

## Project Objectives

- Analyze delivery delays.
